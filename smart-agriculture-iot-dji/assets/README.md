# Assets Directory

## 目录说明
`assets/` 目录用于存放项目的资源文件。

## 预期的资源文件
### 1. 图片资源
- 应用图标 (各种尺寸)
- 界面背景图片
- 按钮图标
- 无人机状态指示图标
- 传感器图标
- 农作物相关图片

### 2. 配置文件
- JSON配置文件
- 地图样式文件
- 无人机配置文件
- MQTT服务器配置模板

### 3. 数据文件
- 示例传感器数据文件
- 地图覆盖物数据
- 飞行航线示例数据
- 用户手册PDF文件

### 4. 字体文件
- 中文字体文件
- 图标字体文件

### 5. 其他资源
- 视频演示文件
- 项目展示图片
- 设计稿文件
- 第三方库的本地缓存文件

## 当前状态
目前此目录为空，因为在从DOCX文档提取代码的过程中：
1. 原始DOCX文档主要包含Java源代码文本
2. 图片、配置文件等二进制资源未被包含在DOCX中
3. 需要从原始Android Studio项目中获取完整的资源文件

## 使用建议
如果需要恢复完整的Android项目，应该：

1. **从原始项目复制**：从原始的Android Studio项目中复制完整的资源文件
2. **重新设计制作**：根据应用功能重新设计制作必要的资源文件
3. **使用占位资源**：在开发初期可以使用简单的占位资源
4. **按需添加**：根据实际功能需求逐步添加资源文件

## 资源文件组织建议
建议按照以下结构组织资源文件：

```
assets/
├── images/          # 图片资源
│   ├── icons/       # 图标
│   ├── backgrounds/ # 背景图片
│   └── ui/          # 界面元素图片
├── configs/         # 配置文件
│   ├── mqtt/        # MQTT配置
│   ├── map/         # 地图配置
│   └── drone/       # 无人机配置
├── fonts/           # 字体文件
├── data/            # 数据文件
└── docs/            # 文档文件
```

## 注意事项
1. **版权问题**：确保使用的资源文件具有合法的使用权限
2. **文件大小**：注意资源文件大小，避免应用体积过大
3. **分辨率适配**：为不同屏幕密度提供适当的资源版本
4. **命名规范**：使用有意义的文件名，便于维护
