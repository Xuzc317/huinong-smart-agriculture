# 系统功能列表

## 一、用户管理功能
1. **注册登录**
   - 用户注册（账号、密码）
   - 用户登录
   - 自动登录
   - 退出登录

2. **个人信息管理**
   - 个人信息查看
   - 信息修改
   - 头像设置

3. **密码管理**
   - 修改密码
   - 密码找回

## 二、农田环境监测功能
1. **数据展示**
   - 环境温度实时显示
   - 环境湿度实时显示
   - 土壤湿度实时显示
   - 历史数据图表

2. **数据管理**
   - 数据刷新
   - 数据存储
   - 数据导出

## 三、灌溉控制功能
1. **控制模式**
   - 手动灌溉控制
   - 自动灌溉模式（基于阈值）
   - 定时灌溉

2. **设备状态**
   - 水泵开关状态
   - 灌溉时长设置
   - 灌溉记录

## 四、MQTT通信功能
1. **连接管理**
   - MQTT服务器连接
   - 连接状态监控
   - 自动重连

2. **数据通信**
   - 传感器数据订阅
   - 控制指令发布
   - 主题管理

## 五、飞行报备功能
1. **报备管理**
   - 飞行计划提交
   - 报备记录查询
   - 报备状态跟踪

2. **权限管理**
   - 飞行权限验证
   - 区域限制检查
   - 时间限制管理

## 六、无人机连接功能
1. **设备连接**
   - DJI无人机搜索
   - 蓝牙/USB连接
   - 连接状态监控

2. **设备状态**
   - 电池电量显示
   - GPS信号状态
   - 飞行模式显示
   - 设备信息查看

## 七、基础控制功能
1. **飞行控制**
   - 起飞/降落
   - 悬停
   - 紧急停止

2. **相机控制**
   - 拍照
   - 录像开始/停止
   - 相机模式切换

## 八、航点规划功能
1. **航线设计**
   - 地图选点
   - 航点添加/删除
   - 航线预览

2. **飞行任务**
   - 任务上传
   - 自动飞行
   - 任务进度监控

## 九、媒体文件管理功能
1. **文件浏览**
   - 照片浏览
   - 视频播放
   - 文件列表

2. **文件操作**
   - 文件下载
   - 文件删除
   - 文件分享

## 十、地图服务功能
1. **地图显示**
   - 农田位置标注
   - 无人机实时位置
   - 飞行轨迹显示

2. **地图操作**
   - 缩放
   - 平移
   - 定位

## 十一、系统设置功能
1. **应用设置**
   - MQTT服务器配置
   - 地图服务配置
   - 通知设置

2. **关于信息**
   - 应用版本
   - 开发者信息
   - 使用帮助

## 功能特点总结
1. **多技术集成**：集成物联网、移动应用、云平台、无人机技术
2. **实时性**：实时数据监测和控制
3. **自动化**：支持自动灌溉和自动飞行
4. **可视化**：数据图表和地图可视化展示
5. **扩展性**：模块化设计便于功能扩展
