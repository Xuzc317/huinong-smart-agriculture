# 智慧农业物联网系统与DJI集成项目

## 项目概述
本仓库包含一个**团队项目**/**课程项目**/**竞赛项目**的整理源代码和文档 - 这是一个集成物联网传感器、Android移动应用、MQTT通信、云服务和大疆DJI无人机控制的智慧农业系统原型。

该系统展示了现代农业管理中现代技术的集成应用，包括环境监测、自动灌溉和使用无人机进行航拍监测等功能。

## 技术栈
- **移动平台**：Android应用（Java/Kotlin）
- **物联网通信**：MQTT协议
- **云服务**：百度智能云
- **地图与导航**：高德地图SDK
- **无人机控制**：大疆DJI Mobile SDK V4
- **开发环境**：Android Studio 2023.1.1, Java 1.8
- **数据库**：SQLite（本地）、云端数据库

## 系统功能
- **用户管理**：注册、登录、个人资料管理、密码修改
- **环境监测**：温度、湿度、土壤湿度的实时显示
- **灌溉控制**：手动/自动灌溉模式、水泵控制
- **无人机操作**：DJI无人机连接、状态监控、飞行报备
- **航拍监测**：实时视频流、拍照/录像、航点规划
- **数据可视化**：环境数据图表、基于地图的农田可视化
- **通信功能**：基于MQTT的传感器数据传输和设备控制

## 敏感信息处理
出于安全考虑，代码中的所有敏感信息已替换为占位符值：

### 已替换内容
- **API密钥和密码**：所有硬编码的API密钥、密码和令牌
- **服务器地址**：MQTT代理URL、云服务端点
- **凭证信息**：用户名、密码、访问令牌
- **个人信息**：邮箱地址、电话号码
- **配置详情**：特定服务器配置

### 替换示例
```java
// 原始代码（出于安全已移除）
private String host = "tcp://127.0.0.1:1883";
private String password = "actual_password123";

// 替换后代码
private String host = "tcp://YOUR_MQTT_HOST:1883";
private String password = "YOUR_MQTT_PASSWORD";
```
