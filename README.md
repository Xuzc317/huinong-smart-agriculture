# huinong-smart-agriculture

## 项目简介

本项目围绕智慧农业场景，结合物联网传感器、Android 移动端、MQTT 通信、百度智能云、高德地图 SDK 和 DJI Mobile SDK，构建一个智慧立体农业系统原型。
系统主要支持农田环境数据展示、灌溉控制、飞行报备、无人机连接、基础控制、航点规划和航拍图像传输等功能。

> 说明：本项目为团队项目，本仓库主要用于整理项目功能、技术栈、个人参与内容和比赛成果。

---

## 技术栈

- Android Studio
- DJI Mobile SDK
- 高德地图 SDK
- MQTT
- 百度智能云
- STM32 / ESP 类单片机
- 传感器数据采集

---

## 项目背景

传统农业管理中，农田环境数据采集、灌溉控制和农田巡检通常依赖人工操作，效率较低。  
本项目尝试通过传感器、云平台、移动端 App 和无人机模块的结合，实现农业环境数据的实时查看和农业作业的辅助管理。

---

## 核心功能

### 1. 用户注册与登录

- 用户注册
- 用户登录
- 修改密码
- 个人信息管理

### 2. 农田环境数据展示

- 环境温度
- 环境湿度
- 土壤湿度
- 传感器数据展示

### 3. 灌溉控制

- 水泵控制
- 手动灌溉
- 自动灌溉模式
- 农田灌溉提示

### 4. 飞行报备

- 城市飞行报备入口
- 跳转无人机飞行报备网址

### 5. 无人机连接与控制

- DJI 设备连接
- 无人机状态显示
- 电量、高度、速度、距离、卫星数等参数展示
- 拍照与录像
- 视频流预览

### 6. 航点规划

- 高德地图定位
- 航点添加与清空
- 飞行参数配置
- 航点任务上传、开始、暂停和停止
